Conexión a Supabase DB

Conecte el backend en la nube con sus credenciales de Supabase.

ℹ️ Guía de Conexión:

1. Ejecute el archivo supabase/schema.sql en el Editor SQL de su proyecto en Supabase.

2. Copie la URL del Proyecto y la clave Anon pública desde la sección Project Settings → API.

3. Guarde los cambios aquí. La aplicación se sincronizará automáticamente con su base de datos.
